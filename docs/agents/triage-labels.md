# Triage labels

- needs-triage: not yet specified.
- needs-info: a specific human or empirical answer is needed.
- ready-for-agent: specified work; check native prerequisites before claiming.
- ready-for-human: explicit human acceptance or action.
- wontfix: only after the owner explicitly removes scope; never a shortcut around acceptance.

Additional labels: kind:spec, kind:feature, kind:setup; area:simulation, area:building, area:art, area:platform, area:ux, area:content, area:qa; priority:high and priority:normal; wayfinder:map, wayfinder:grilling and wayfinder:prototype.
