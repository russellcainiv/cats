# Cats Implementation Plan

> **For agentic workers:** Use the execution workflow available in your environment to implement this plan task by task. If Superpowers is available, use subagent-driven-development or executing-plans. No particular model, provider or delegation method is required. Steps use checkbox syntax for tracking.

**Goal:** Deliver a private, fully playable browser cat life simulation with the approved art, full house building, meaningful lives and consequences, and automatic computer/phone saves.

**Architecture:** One deterministic headless world simulation owns all state. A client-only Pixi renderer displays it, React supplies accessible controls, and authenticated transactional cloud snapshots plus local checkpoints preserve it across devices.

**Tech Stack:** Proposed defaults: TypeScript, Next.js App Router, React, PixiJS 8, IndexedDB, Neon Postgres, Clerk, Vitest and Playwright. Resolve supported package versions from official docs at implementation time and commit the lockfile. No runtime LLM is required.

**Spec:** [.scratch/cats/spec.md](../../../.scratch/cats/spec.md). Also read [architecture](../../architecture.md), [integration contracts](../../contracts.md), and [confirmed requirements](../../requirements.json).

![Approved A + B game art direction](../../art/approved-direction.png)

## Global Constraints

- Whole household of cats with personalities and free will; every agreed play pillar remains in scope.
- Both phone and computer are first-class; use the approved A + B picture as art direction, not a static game substitute.
- Eight living household cats maximum, including kittens; unborn reservations prevent over-capacity births.
- Moo-Moo can be player-suggested or autonomous; both cats must be in love, willing and in the mood. Kittens are a chance.
- At capacity Moo-Moo is allowed but cannot start a new pregnancy.
- Death and permanent loss are real; memorials and ghost visits do not resurrect cats.
- Lifespan is fixed between normal and slow, not player-adjustable. No time progresses while closed.
- Private game access and owner-isolated saves; public source does not mean public registration.
- Preserve all acceptance criteria. A ticket is not complete because a PR, screenshot or partial test exists.

## Review Focus

1. Two devices plus a lost response: a stale tab must not overwrite newer play. Test 03 and 29.
2. Seven cats, pregnancy, adoption and simultaneous conception: reservations must keep living count at eight. Test 19, 20 and 25.
3. Hidden/closed browser during a hazard or pregnancy: reopening must not advance any simulation time. Test 03, 19, 21 and 22.
4. Free-build sale, undo or goal claim: no conversion into earned cash, resurrection or duplicate rewards. Test 09, 10 and 14.
5. Mobile pan/pinch, keyboard and safe areas: accidental gestures must not commit construction or Moo-Moo, and no action may become unreachable. Test 07, 08, 19 and 28.

test('sync-and-pause: second device fences stale saves', async ({ page, browser }) => {
  const { householdId } = await openScenario(page, 'sync-and-pause');
  const saveRequest = page.waitForRequest(r => r.url().endsWith('/save'));
  await page.getByRole('button', { name: 'Pause', exact: true }).click();
  const oldWrite = (await saveRequest).postDataJSON();
  await expect(page.getByTestId('save-status')).toHaveText('Saved');
  const before = await readCommittedView(page, householdId);
  const secondContext = await browser.newContext({ storageState: await page.context().storageState() });
  const second = await secondContext.newPage();
  await second.goto(page.url());
  await second.getByRole('button', { name: 'Continue here', exact: true }).click();
  expect((await readCommittedView(second, householdId)).view.simMinute).toBe(before.view.simMinute);
  const stale = await page.request.post('/api/households/' + householdId + '/save', {
    data: { ...oldWrite, requestId: crypto.randomUUID(), expectedRevision: before.revision }
  });
  expect(stale.status()).toBe(409);
  expect((await readCommittedView(second, householdId)).checksum).toBe(before.checksum);
  await secondContext.close();
});
